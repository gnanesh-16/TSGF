⚡ Board Orchestrator

The orchestrator strictly coordinates wave batches, resolves task dependency DAGs, and dispatches isolated workers. Never writes product code directly in the orchestrator session.

🔨 Isolated Worker Lanes

Build creates an isolated worktree under .claude/worktrees/, QA proves ACs with runtime tests & screenshot sheets, and Review performs adversarial verification.

🔄 Closed-Loop Auto-Remediation

When QA tests fail or Review requests changes, the task bounces back to Building with structured, diff-level failure context for autonomous self-healing.

🛡️ Deterministic Safety Guards

Python stdlib hooks block credential leaks, live API keys, deletion outside project boundary, and unauthorized pushes to main.

🚀 Multi-Host Architecture

Maintains canonical skills, scripts, and workflows inside .agents/ and dynamically symlinks into Antigravity IDE, Claude Code, and Codex.

🛰️ Signal Collection Engine

Mines production exceptions, funnel drops, and architectural smells from Sentry, PostHog, and GitHub, filing verified Backlog tickets.

Deterministic Guard Hooks

Standard Python stdlib hooks executing pre-command checks to keep agent runs safe.

Hook Name Protection Boundary Action on Violation Status
guard-worktree-path.py Restricts git worktree add to .claude/worktrees/ Halts command execution (exit 1) ● Active
guard-secrets.py Blocks reading/dumping .env, SSH keys, credentials Halts command execution (exit 1) ● Active
guard-key-literals.py Detects live unredacted API keys/tokens in file writes Rejects file modification (exit 1) ● Active
guard-delete-outside.py Blocks rm -rf targeting outside project or /, ~ Halts command execution (exit 1) ● Active
guard-protected-push.py Blocks direct or force pushes to main or master Rejects git push (exit 1) ● Active
cleanup-wt.py Removes merged worktrees and logs recovery records Prunes merged branches post-merge ● Active
