# `/ui-refine-loop` — UI Polish & Refinement Loop

A structured design loop that polishes user interfaces:
1. **Critique**: Audits contrast, hierarchy, typography, padding, micro-animations, and responsiveness.
2. **Refine**: Makes targeted CSS/DOM updates using design tokens (avoiding generic primary colors, ensuring sleek dark mode, refined border radiuses, and smooth transitions).
3. **Capture & Compare**: Takes browser snapshots before and after each iteration.
4. **Ledger**: Tracks improvements and prevents visual regressions.

## Usage
```bash
/ui-refine-loop <route-or-component-file>
```
