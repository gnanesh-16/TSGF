# `/visual` — Interactive Codebase Visualizer

Generates a standalone, beautiful HTML report with interactive diagrams, pan/zoom canvas, and dark/light mode toggles.

## Modes

- `/visual recap`: Visual summary of commits, diffs, and proof of tests on the current branch.
- `/visual plan`: Dependency graph of planned waves and tasks.
- `/visual path`: Interactive codebase map showing module relationships.
