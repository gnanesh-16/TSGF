Autonomous software delivery with proof.
Built for agent teams that ship.

TSGF eliminates human micromanagement. Tasks progress through automated verification stages while deterministic guard hooks keep your repository secure.

🌲 Isolated Worktree Sandboxes

Lane 1 creates isolated git worktrees for every task under .claude/worktrees/, keeping changes under the 400-line cap test-first.

"Zero pollution of your primary working directory."

📸 Automated Visual Proof

Lane 2 executes headless browser tests and captures responsive screenshots across desktop and mobile viewports pinned to commit SHAs.

"Every UI pull request has visible proof."

🔄 Closed-Loop Auto-Remediation

When QA tests fail or Review requests changes, the card bounces back to Building with structured, diff-level failure context for autonomous self-healing.

"Autonomous test-fix-recheck loop."

🧐 Adversarial Review Memory

Lane 3 reviews code against historical regressions stored in .claude/tsgf/review-memory.json, preventing recurring architectural debt.

"Remembers every past review finding."

🛡️ Deterministic Guard Hooks

Python stdlib hooks block credential leaks, live high-entropy API keys, destructive deletions outside project boundaries, and direct pushes to main.

"Limits live in the harness, not LLM probability."

🛰️ Signal Mining Telemetry

/tsgf-collect mines unresolved exceptions and friction from Sentry, PostHog, and GitHub, filing verified Backlog cards automatically.

"Bugs discovered before users report them."
